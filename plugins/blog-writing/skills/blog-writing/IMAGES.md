# 이미지·다이어그램 원칙

본문에 이미지가 들어가는 순간 참조한다.

- **설정 절차는 CLI 텍스트 유지** (재현성, UI 변경에 강함). 콘솔 캡처는 두 용도만: ①옵션 선택 화면(본문 개념과 1:1 대응되는 라디오버튼 등, 민감정보 없음) ②결과 확인 목록(생성된 리소스 증거)
- 다이어그램은 **본문 서사와 정합** 필수 — 온프렘 리소스는 온프렘 박스에, 호출 주체·방향이 본문 흐름과 일치. 트래픽은 실선, 설정 관계(인증서 연결, DNS 레코드)는 점선으로 구분
- 그림이 복잡해지면 요소를 추가하는 대신 **"간략화했다"는 캡션 주석으로 상세 섹션에 위임**
- 캡처 위치: 비교표의 근거가 되는 캡처는 표 바로 위, 구조 다이어그램은 해법 선언 문장과 단계 목록 사이(지도 먼저, 길 안내 나중)
